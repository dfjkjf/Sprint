## 用法

- 每题念出声。念不顺，说明只是读懂了，不是会了。
- 同一题隔天脱离文字复述一遍。讲不成整句的，回头重读。
- 拿不准的先标出来，核对完代码或文档再定稿，不带着猜测进面试。
- 尾延迟、内存带宽这类问题，没有具体数字就不要断言。
