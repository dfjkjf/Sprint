# 主管面

一面判断「会不会」，这一轮判断「能不能自己扛一个模块」——架构判断、资源组织、对外承诺。题型是场景式：给一个局面要方案。这一轮答错不是减分，是直接判「不到平台工程师」。

## 考什么

| 维度 | 判定标准 |
| --- | --- |
| 架构判断 | 信息不全时能不能定边界、定接口、定降级方案 |
| 技术选型 | 能不能说清取舍、代价、失效条件，而不是只讲优点 |
| 接口契约 | 跨团队接口怎么定、边界冲突怎么收敛、变更怎么治理 |
| 承诺与风险 | 敢不敢给时间点，给的时候有没有留出验证和回归 |
| 向上沟通 | 能不能把技术问题翻译成业务影响 |

## 与其他两轮的分界

- 不考基础原理。原理讲不清是一面的问题，这里默认已经会了。
- 不考动机与薪资，那是 HR 面的范围；但「为什么值得给你这个岗位」要能答。
