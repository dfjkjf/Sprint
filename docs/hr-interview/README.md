# HR 面

不谈技术，只谈风险。HR 要判断的是「这个人来了会不会出问题、走了会不会留坑」——动机、薪资、稳定性、协作方式。

这一轮挂掉的人往往技术没问题，而是前后说法不一致，或者把谈判姿态摆得太早。

## 考什么

| 维度 | 判定标准 |
| --- | --- |
| 动机 | 为什么是这家公司、这个岗位，与职业规划能对上 |
| 离职原因 | 只说事实和判断，不评价前东家、不抱怨 |
| 薪资 | 期望有依据，能说清区间和弹性，不临场改口 |
| 稳定性 | 履历连续性、跳槽节奏、地域与家庭因素说得通 |
| 协作 | 冲突处理、跨团队配合，有具体例子而不是形容词 |
| 边界 | 背调、竞业、到岗时间，有没有隐藏风险 |

## 一致性要求

同一个事实在三轮里必须有同一个说法：离职原因、项目归属、薪资构成、到岗时间。HR 会拿你在技术面的表述和这里对照，不一致比答错更致命。
