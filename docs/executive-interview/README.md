# 总裁面

与技术判断无关，考的是「值不值得投资」：行业理解、稳定性、成长性、成本匹配。通常与主管面同一场进行，由更高层接续，但考点完全不同，所以单独备料。

这一轮的特点是：**技术答得再好也救不回一个含糊的动机，或者一个说不通的薪资。**

## 考什么

| 维度 | 判定标准 |
| --- | --- |
| 行业判断 | 说清目标行业当前的技术趋势，以及你在其中的位置 |
| 成本匹配 | 期望薪资与产出之间有一条说得通的账 |
| 稳定性 | 上一份为什么走、这一份为什么来，两句话能对上 |
| 成长性 | 三年后你解决什么问题，不是「升到什么职位」 |
| 风险项 | 年龄、地域、家庭、竞业，有没有一票否决的隐患 |

## 材料

按行业分开。两个行业问的其实是不同的问题——汽车判断你能不能守住一个成熟平台，机器人判断你能不能从零立一个标准。
